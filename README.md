# Unpack-client

## ALT2

نسخة C++17 جديدة لفك حزم ALT2 الموجودة داخل `alt2/pack` أو `alt2/data` (والعينة الحالية هي `data/root`) واستخراج مفتاحها من `alt2/metin2client.exe` دون تشغيل العميل أو تعديل الملفات الأصلية. تمسح المجلدات الفرعية وتتيح اختيار حزمة بالاسم أو فكّ الجميع، ويمكن بناؤها كبرنامج مستقل باستخدام Visual Studio 2022.

- [مشروع Visual Studio وتعليمات البناء والتشغيل](alt2/cpp/README.md)
- [تعليمات التشغيل والنتائج](alt2/README.md)
- [نسخة Python المرجعية](alt2/unpack.py)
- [توثيق بنية الحزمة والتحليل](alt2/FORMAT.md)

نسخة C++ لا تحتاج إلى Python أو مكتبات خارجية، وتتحقق من حجم وبصمة XXH32 لكل ملف قبل الاستخراج. كلتا النسختين مخصصتان لبنية عينة ALT2 المرفقة، وليستا أداتين عامتين لجميع عملاء Metin2.

## History

أداة منفصلة لفك حزم `History/pack/*.d2` والتحقق من محتوياتها واستعادة أسماء ملفاتها ومساراتها الحقيقية دون تشغيل العميل:

- [التعليمات والنتائج](History/README.md)
- [الأداة](History/unpack.py)
- [توثيق الصيغة وتحليل العميل](History/FORMAT.md)

مفتاح هذه العينة موجود في رأس الحزمة نفسها؛ يُستخدم `History2.exe` لتحديد طريقة استخدامه والتحقق من نسخة العميل، لا لادعاء استخراج مفتاح ثابت غير موجود فيه. تتطلب الأداة `pycryptodome` و`lz4` و`xxhash` وفق [History/requirements.txt](History/requirements.txt).
