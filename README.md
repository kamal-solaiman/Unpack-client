# Unpack-client

## ALT2

أداة Python لفك حزم `alt2/data/root` واستخراج مفتاحها من `alt2/metin2client.exe` دون تشغيل العميل أو تعديل الملفات الأصلية.

- [تعليمات التشغيل والنتائج](alt2/README.md)
- [الأداة](alt2/unpack.py)
- [توثيق بنية الحزمة والتحليل](alt2/FORMAT.md)

تتطلب Python 3.10 أو أحدث، وحزمتي `lz4` و`xxhash`. الأداة مخصصة للصيغة الموجودة في عينة ALT2 المرفقة، وليست أداة عامة لجميع عملاء Metin2.

## History

أداة Python لفك حزم `History/pack/workplace.d2` بصيغة **AES-256-CFB + LZ4 + XXH32**، مع اشتقاق هندسة الصيغة والمفتاح من `History/History2.exe` بتحليل ثابت فقط، دون تشغيل العميل أو تعديل الملفات الأصلية.

- [تعليمات التشغيل والنتائج](History/README.md)
- [الأداة](History/unpack.py)
- [توثيق بنية الحزمة والتحليل](History/FORMAT.md)

تتطلب Python 3.10 أو أحدث، وحزم `lz4` و`xxhash` و`pycryptodome`. مفتاح هذه الحزمة مخزّن داخل رأس الحزمة نفسها (32 بايت AES-256 و16 بايت لمتجه التهيئة)، بينما يحدّد العميل كيفية قراءته؛ ترفض الأداة أي إصدار عميل لا تُثبت شيفرته هذه الهندسة. النتائج المتحققة: 813 ملفًا، جميعها اجتازت فحص XXH32، واستُعيد 812 اسمًا آليًا.
