# فك حزمة History — `workplace.d2`

أداة Python تفك حزم `History/pack/*.d2` **دون تشغيل** `History2.exe` أو ملفات Python المستخرجة، ودون تعديل المدخلات. النتائج تخص نسخة العميل والحزمة المرفقتين؛ ليست دعمًا عامًا لكل ملفات `.d2`.

## التثبيت والتشغيل

Python 3.10+، من جذر المستودع:

```bash
# Linux / macOS
python3 -m venv .venv
.venv/bin/python -m pip install -r History/requirements.txt
.venv/bin/python History/unpack.py key
.venv/bin/python History/unpack.py list
.venv/bin/python History/unpack.py verify
.venv/bin/python History/unpack.py extract
```

```powershell
# Windows PowerShell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r History/requirements.txt
.venv\Scripts\python.exe History\unpack.py key
.venv\Scripts\python.exe History\unpack.py verify
.venv\Scripts\python.exe History\unpack.py extract
```

الموضع الافتراضي لمعطى `archive` هو **مجلد الحزم** `History/pack`؛ إذا احوى حزمة واحدة (وضع العينة حاليًا) تعمل الأوامر عليها مباشرة دون أي سؤال. النتيجة الافتراضية `History/unpacked/<اسم الحزمة>/` (مستبعدة من Git).

### الاختيار عند وجود أكثر من حزمة داخل المجلد

إذا وجد المجلد أكثر من ملف `.d2` يطلب الأمر — عند وجود طرف إدخال — الاختيار صراحةً:

```text
3 packs found:
  [1] icon.d2 (6,126,018 bytes)
  [2] locale.d2 (6,126,018 bytes)
  [3] workplace.d2 (6,126,018 bytes)
Extract a specific pack or all? Enter a number (e.g. 1), a list (1,3), or 'a' for all:
```

أي رقم لحزمة معيّنة، أو قائمة أرقام بفواصل، أو `a`/`all` لفكّ الجميع. أمثلة:

```bash
# في الطرفية: يسأل — ملف معيّن أم الجميع؟
.venv/bin/python History/unpack.py extract History/pack

# في السكربات (stdin ليست طرفًا): لا يوجد سؤال، حدّد ما تريد صراحةً
.venv/bin/python History/unpack.py extract --all                 # كل حزم المجلد
.venv/bin/python History/unpack.py extract --file workplace       # بالاسم أو بدون امتداد (يمكن تكراره)
.venv/bin/python History/unpack.py extract History/pack/workplace.d2   # ملف محدد مباشرة
```

بدون `--all` أو `--file` وبدون طرفية تُعرض رسالة خطأ تشرح الخيارات بدل الانتظار إلى الأبد. أوامر `key` و`list` و`verify` تقبل نفس الاختيار ونفس الخيارات.

### قواعد مجلد الإخراج

- **حزمة واحدة** (بأي طريقة اختيار): `--output` هو مجلد النتيجة نفسه، والافتراضي `History/unpacked/<اسم الحزمة>`.
- **عدة حزم**: `--output` هو المجلد الأب ويُنشأ لكل حزمة مجلد فرعي باسمها (والافتراضي `History/unpacked/`).

```bash
.venv/bin/python History/unpack.py extract History/pack/workplace.d2 -o History/unpacked/workplace-2
.venv/bin/python History/unpack.py extract History/pack --all -o History/unpacked/all
```

أي مجلد نتيجة مطلوب **لا يجوز أن يكون موجودًا مسبقًا**؛ لا تكتب الأداة فوق الملفات السابقة، وتفحص كل المجلدات المطلوبة قبل البدء بأي استخراج. `verify` يتحقق من كل الملفات بلا إنشاء نتائج. `list` يعرض الفهرس فقط ولا يفك المحتوى. يمكن ضبط حدود الأمان بالبايت باستخدام `--max-file-size` و`--max-total-size` عند التعامل مع مدخلات موثوقة كبيرة.

## استعادة الأسماء والمسارات الحقيقية

لا يخزّن رأس الحزمة اسم الملف، بل `name_hash` = **CRC32 للاسم الافتراضي** بعد توحيد صيغته (أحرف صغيرة وفاصل `/`). لا تخمّن الأداة الأسماء؛ تبني مرشحين ثم **لا تقبل أي مرشح إلا إذا كان CRC32 له مساويًا تمامًا لبصمة المدخل**:

1. نصوص `History2.exe` (مسارات `.py` و`.pyc` وغيرها) — دون تشغيله.
2. محتوى الحزمة نفسه بعد فكّه: مراجع المسارات داخل الملفات، واستيرادات Python، والتجميعات النصية الثابتة (`x = "dir/" + "name.py"`) دون تنفيذ أي شي، و`co_filename` المدمج داخل ملفات `.pyc`.
3. اشتقاق أزواج المتناظرين: إذا عُرف `foo.py` تُجرَّب `foo.pyc` للملف المقابل والعكس.
4. قائمة أسماء إضافية: `History/names.txt` تُحمَّل تلقائيًا، وأي ملفات `--names` (اسم في كل سطر، UTF-8، والتعليقات بـ `#`)؛ المطلوب للاسم أن يطابق بصمة أحد الملفات وإلا رُفض.

عند تعدد مرشحين مختلفين لبصمة واحدة (تصادم نظري) يبقى الملف دون اسم ويُذكر مرشحوه في `manifest.json`. كل مسار يُقبل للكتابة يجب أن يكون نسبيًا آمنًا: لا `..` ولا مسارات مطلقة ولا أسماء محظورة على ويندوز.

مخرجات `extract`:

```text
History/unpacked/workplace/
├── files/                 # الأسماء والمسارات الحقيقية المستعادة
│   ├── cammodule.py
│   ├── claude.md
│   ├── colorinfo.py
│   ├── game.py
│   ├── uiscript/          # الملفات التي كانت داخل مجلدات
│   │   ├── gamewindow.py
│   │   └── ...
│   └── ...
├── unknown/               # محتوى متحقق منه بلا اسم فريد (إن وجد)
│   └── 0003_abcd1234.py
└── manifest.json          # لكل ملف: البصمة والاسم والمرشحات والإزاحات والحجم وSHA-256
```

امتداد الملفات داخل `unknown/` تصنيف تقريبي من المحتوى `.py`/`.pyc`/`.bin` وليس اسمًا مسترجعًا. مطابقة CRC32 دليل عملي وليست برهانًا رياضيًا للاسم الأصلي؛ احتمال التصادم ضئيل لكنه غير معدوم، ولهذا تُسرد المرشحات في الفهرس لكل ملف.

## أين يوجد المفتاح؟

التحليل الثابت لـ `History2.exe` يبيّن أن العميل يقرأ أول `0x44` بايت من الحزمة: توقيع `0xF00FED5C`، ثم **مفتاح AES-256 بطول 32 بايت**، ثم **32 بايت من مادة IV**. يستخدم AES-CFB أول 16 بايت من مادة IV؛ ويمكن لعميل History تطبيق قناع XOR إضافي مرتبط باسم الحزمة، لكن `workplace.d2` المرفقة تُفك بنجاح **من دون قناع إضافي**. ولذلك، **المفتاح الفعّال لهذه الحزمة مستخرج من رأس `.d2`، وليس سرًا ثابتًا مستخرجًا من ملف EXE**. يُستخدم `History2.exe` لمعرفة خوارزمية القراءة والتشفير، ويطابق أمر `key` بصمته مع النسخة التي تم تحليلها؛ لن يدّعي العثور على مفتاح داخل EXE خلافًا للواقع.

المفتاح لهذه العينة (hex):

```text
4d2f40854e9df31cb095c62702992a0f0e35f6416a5456b94e3d9fefad1de7b8
```

الفك: AES-256-CFB مع مقطع تغذية راجعة 128 بت وإعادة التهيئة لكل ملف، ثم raw LZ4 عند الحاجة، ثم التحقق من الحجم وXXH32 ببذرة `0xF00FED5C`. التفاصيل والإزاحات في [FORMAT.md](FORMAT.md).

## النتائج المتحققة للعينة المرفقة

| البند | النتيجة |
|---|---:|
| حجم الحزمة | 6,126,018 بايت |
| عدد الملفات | 813 |
| الحجم بعد الفك | 16,929,395 بايت |
| الملفات المطابقة لفحص XXH32 | 813 / 813 |
| الأسماء والمسارات المستعادة | 813 / 813 |
| الملفات دون اسم فريد | 0 |

أمثلة على أسماء مستعادة بمساراتها: `colorinfo.py`، `game.py`، `claude.md`، `uiscript/gamewindow.pyc`، `ui_fundamentals.md`. بعض المحتوى **Python 2.7 bytecode** محفوظ كما هو بصيغة `.pyc`، وليس مصدر Python مفكوكًا أو برنامجًا يتم تشغيله.

المدخلات غير الموثوقة تُفحص من حيث توقيع الحزمة، وحدود الرؤوس والحمولات، والحدود القصوى للأحجام، والطول وبصمة XXH32 لكل ملف. يكتب `extract` إلى مجلد مؤقت ولا ينشر النتائج إلا بعد نجاح الجميع؛ ويحذف المجلد المؤقت عند الفشل. لا تفتح أو تشغل الملفات المستخرجة إلا بعد فحصها بنفسك.

## الاختبارات

```bash
.venv/bin/python -m unittest discover -s History/tests -v
HISTORY_FULL_TEST=1 .venv/bin/python -m unittest discover -s History/tests -v
```

الاختبارات تغطي الفك والتحقق، واستعادة الأسماء من المحتوى والأزواج وقوائم الأسماء، وقواعد الاختيار بين الحزم ومتعددها، ورفض الإنتاج غير الكامل. الاختيار الأخير (المفعَّل بـ `HISTORY_FULL_TEST=1`) يتحقق من كل ملفات العينة **ويتأكد من استعادة 813/813 اسمًا** مع بصمة العميل المرفق. لا يُشغَّل الملف التنفيذي في أي خطوة.
